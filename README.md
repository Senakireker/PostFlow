# PostFlow

PostFlow is a simple social media-style web application built with React.

Users can share their thoughts, express their mood, like posts, search content, filter posts by mood, edit posts, and delete posts.

✅ Create new posts

## Installation

Clone the repository:

```bash
git clone https://github.com/Senakireker/PostFlow.git
```

Go to the project directory:

```bash
cd PostFlow
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

---

## Build

Create a production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
