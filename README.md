# PostFlow

A simple social media platform built with React.

## Features

- Create posts
- Edit posts
- Delete posts
- Like / Unlike system
- Mood selection with emojis
- Search posts
- Mood filtering
- LocalStorage persistence
- Responsive design

## Installation

```bash
npm install
npm run dev
```
